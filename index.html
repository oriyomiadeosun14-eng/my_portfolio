Expense Tracker

A full-stack personal finance app built with Next.js, TypeScript and MySQL. Users can log expenses, sort them into categories, and see where their money goes. I also built the whole account system myself.

  • Sign-in and sessions use NextAuth, and changing your password signs you out on every device
  • Account emails go through Resend: a new email address is confirmed before it's used, and the old address can undo the change for three days
  • Deleting an account removes all of the user's data in a single Prisma transaction, so nothing is left half-deleted
  • Tested against wrong passwords, expired or reused links, and old sessions

Data science

Global Safety Analysis

A data analysis of the Global Peace Index across 161 countries from 2008 to 2025. It answers three questions: which countries are safest, which are least safe, and why a country scores the way it does.

  • Ranks every country by its peace score and charts the 15 safest and 15 least safe
  • Explains a country's score by comparing its three parts (ongoing conflict, safety and security, militarization) with the global average
  • Interactive world map: hover a country for its rank, click it for a card with its flag, main driver of insecurity and a 2008–2025 trend line

What I build with

Interface

HTML
The structure of a page — headings, forms and the landmarks screen readers depend on.
CSS
Layout, spacing and responsive behaviour, so a page holds up on a phone as well as a laptop.
React
Builds the interface out of reusable components instead of repeating the same markup.

Languages

JavaScript
The language the browser runs — everything that responds to a click or a keystroke.
TypeScript
JavaScript with types added, so mistakes surface while I am writing rather than after it ships.

Framework

Next.js
The React framework I build in. Routing, server rendering and the API layer all live in one project.

Database

Prisma
The layer between my code and the database — typed queries, and migrations when the schema changes.
MySQL
Relational database. What I reach for by default.
PostgreSQL
Relational database. Chosen when a project needs its stricter types or more capable querying.

Validation

Zod
Checks that data arriving from a form or an API is the shape it claims to be, before it reaches the database.

Version control

Git
Branching per feature, and keeping commits small enough that a change can be read and reversed on its own.
GitHub
Where the work gets reviewed — opening pull requests, reading other people's, and resolving conflicts before a release.
